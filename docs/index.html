Static preview built to match mobile/src/navigation/index.tsx, mobile/src/theme.ts, and the screens in mobile/src/screens/ — a persistent Map, Group Ride, Friends, and Settings in a bottom tab bar. Group Ride redirects to the Map tab's Host mode rather than being its own screen, so only one map ever loads; an active ride shows as a floating bar rather than its own screen. Friends (add/accept/decline/remove, and the per-friend chat) is local mock state here, same as the host roster — the real app talks to a real backend for all of it. The real app also needs the backend running and the LiveKit voice connection, neither of which exist on this page.
