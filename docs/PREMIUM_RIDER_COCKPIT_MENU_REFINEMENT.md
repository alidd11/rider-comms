# Premium Rider Cockpit — Menu-first product refinement

Date: 23 November 2026  
Branch: `feat/premium-cockpit-menu-hub-20261123`  
Scope: **Menu only** in this PR. PWA and native must remain one product.

## Design objective

Turn the Rider Comms avatar menu from a flat miscellaneous list into a coherent starting point for the full rider experience. Keep concise, high-contrast typography and restrained, consistent iconography. The user can reach each existing feature with the same number of taps; no new features are invented.

## Implemented in this PR

- A consistent `Menu` title and 48dp close control.
- The rider's existing avatar, name, handle and **View profile** action.
- A compact three-column on-device ride summary (rides, ride time, miles/kilometres). **These are local recorded rides, not a lifetime account analytics claim**. Original totals and unit calculation remain unchanged.
- Clear **Ride & explore** navigation: Ride (with Live status), Friends (with unread/request count), Routes, and server-entitled Rider Social Beta only.
- Clear **Account & support** navigation: Your plan, Settings, Help & Support.
- Matched PWA/native spacing, icon containers, row heights, section labels and 44–48dp touch targets, with small-phone scrolling rather than truncation.
- PWA visual/browser assertions and native screen accessibility/navigation assertions. Screenshot artifacts for the menu are generated by the browser test.

No routing, settings, profile persistence, presence, voice, vehicle, map, privacy, billing entitlement or safety logic changes. Rider Social entitlement stays server-authoritative. The menu retains Ride Safe movement restrictions.
